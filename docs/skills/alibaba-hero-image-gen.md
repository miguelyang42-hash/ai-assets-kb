## 🤝 三段式握手 SOP

### 第 1 段：启动前必问 5 题（每次运行强制执行）

AI 必须在开始任何作图操作前，向用户逐一确认以下 5 题：

```
【alibaba-hero-image-gen 启动】

在开始作图前，我需要了解以下信息：

Q1. 请上传产品白底图（JPG/PNG，支持多张）
Q2. 产品名称 或 阿里国际站三级类目（例：Hair Dryer / 吹风机 / Yoga Mat）
Q3. 本次需要哪几类主图？（请选择，可多选）
    ① 产品主展示图（极简科技风，突出核心参数）
    ② 多颜色可选（多色矩阵并排展示）
    ③ 多尺寸可选（多规格对比展示）
    ④ 定制 LOGO（OEM/ODM 激光雕刻 / 丝印效果）
    ⑤ 定制包装盒（礼品盒 / 彩盒 / 定制包装展示）
    ⑥ 使用场景（模特 / 生活方式 / 真实使用环境）
Q4. 目标市场 & 行业风格偏好（例：欧美极简 / 东南亚温馨 / 中东奢华 / 专业工业风）
Q5. 本次生成主图数量（1-6 张；若不填，默认与所选类型数量一致）
```

✅ 正例（5 题全部收集完毕后的确认输出）：
```
已收集完毕：
- 产品图：已收到（吹风机白底图）
- 类目：Hair Dryer / 吹风机
- 主图类型：① 产品主展示图  ② 多颜色可选  ⑥ 使用场景（共 3 张）
- 风格偏好：欧美极简科技风
- 生成数量：3 张
即将开始爬取 Alibaba.com Top Ranking 竞品主图风格...
```

❌ 反例（禁止）：
```
好的，我来帮你生成主图！（直接跳过5问开始作图）
```

---

### 第 2 段：爬取 Top Ranking 竞品风格

收集完 5 题信息后，AI 必须：

1. 访问以下 URL（将 `{keyword}` 替换为英文类目关键词）：
   ```
   https://www.alibaba.com/trade/search?SearchText={keyword}&tab=top_ranking
   ```

2. 分析排名前列产品主图，提取以下维度：

```
【竞品风格分析报告】
- 背景色调：（白底 / 渐变 / 场景色）
- 产品摆放角度：（45度斜放 / 正面 / 多角度组合）
- 文字风格：（字体类型 / 颜色 / 标语类型）
- 卖点呈现方式：（参数徽章 / 认证标识 / 配件全家福）
- 整体视觉风格：（极简科技 / 生活方式 / 工业专业）
- 结合用户目标市场的风格建议
```

3. 将风格分析结果作为生图 prompt 的设计依据。

✅ 正例（爬取后输出）：
```
【Top Ranking 竞品风格分析 - Hair Dryer】
背景：纯白或浅灰渐变
构图：45度侧放为主，突出中空/流线型设计
文字：无衬线加粗，深灰/金色，标注 RPM/离子数等参数
卖点：BLDC Motor / Negative Ion / CE认证 徽章
整体：极简科技感（对标 Dyson 视觉语言）
即将按此风格生成 3 张主图...
```

❌ 反例（禁止跳过爬取直接生图）：
```
根据吹风机行业经验，我来直接生成主图...
```

### 第 3 段：逐张生成主图

按用户所选类型，优先调用 `image_edit` 工具（若有产品原型图）或极其精准的 `image_generate` prompt，每张图生成后立即输出并标注类型说明。必须确保生成的图片中产品外观（如吹风机的数显屏位置、手柄按钮、整体色调）与用户原图 100% 一致。

#### 各类型生图规范

**① 产品主展示图**
```
prompt 要素：
- 白色背景，产品多角度展示（正面+侧面）
- 顶部加粗标题（产品英文名）
- 底部 2-3 个核心参数徽章（参考竞品常见标注）
- CE/RoHS/FCC 等认证图标（右下角）
- 极简科技风格，对标 Dyson 视觉
```

**② 多颜色可选**
```
prompt 要素：
- 白色背景，同款产品 3-4 种配色并排或矩阵排列
- 顶部文字：MULTIPLE COLORS AVAILABLE
- 每款下方配色板圆点
- B2B 批发目录风格，清晰展示 SKU 多样性
```

**③ 多尺寸可选**
```
prompt 要素：
- 白色背景，同款产品 2-3 种规格从小到大排列
- 每款下方标注规格参数（重量/尺寸）
- 顶部文字：MULTIPLE SIZES AVAILABLE
- 附尺寸对比参考线
```

**④ 定制 LOGO**
```
prompt 要素：
- 白色或浅灰背景，产品居中
- 产品机身高亮 LOGO 定制区域（激光雕刻/丝印效果）
- 顶部文字：CUSTOM LOGO AVAILABLE
- 副文字：OEM / ODM Service | MOQ 说明
- B2B 贸易目录风格
```

**⑤ 定制包装盒**
```
prompt 要素：
- 白色背景，产品旁边展示精品礼品盒（打开状态+关闭状态）
- 礼品盒盖面留 LOGO 定制区域
- 顶部文字：CUSTOM PACKAGING AVAILABLE
- 副文字：Gift Box | Color Box | OEM Packaging
- 高端零售包装展示风格
```

**⑥ 使用场景**
```
prompt 要素：
- 真实使用场景（根据产品类型匹配对应场景）
- 模特或场景画面自然真实，产品为视觉焦点
- 底部叠加简洁 slogan（英文，符合目标市场文化）
- 温馨/专业/生活方式风格（按 Q4 市场偏好调整）
```

## 📋 输出基准

| 类型 | 规格 |
|---|---|
| 图片尺寸 | 1:1 正方形（800×800px 等效） |
| 背景 | 白底为主（场景图除外） |
| 文字语言 | 英文（B2B 国际买家通用） |
| 风格参考 | 基于当次 Top Ranking 爬取结果 |
| 每张生成后 | 立即展示 + 注明类型 + 提供修改建议 |

## 🔄 完整执行流程

```
[1] 用户触发 Skill
      ↓
[2] AI 发出 5 问（Q1-Q5），等待用户全部回答
      ↓
[3] AI 输出收集确认摘要（范式锁定格式）
      ↓
[4] AI 爬取 Alibaba.com Top Ranking（对应类目英文关键词）
      ↓
[5] AI 输出竞品风格分析报告（范式锁定格式）
      ↓
[6] AI 按所选类型逐张生成主图，每张生成后立即展示
      ↓
[7] AI 汇总输出，提示可修改任意一张
```
