# 聊天框决策摘要模板（v2.5 单 Excel 版 - 含贸易体量）

> AI 在 sanity_check 17/17 PASS 后，必须用此模板输出聊天框摘要。
> 严禁省略、严禁不贴文件链接、严禁不贴自检状态、严禁漏第 10 维贸易体量行。

---

## ✅ 模板（直接套用）

```markdown
## 🎯 {company_full} — 超级背调决策摘要

| 维度 | 关键发现 | 评分 |
|---|---|---|
| 客户层级 | {level} 级（年营收 {trade_total_revenue_usd}） | {⭐ 数} |
| 风险评分 | {risk_score}/100（{风险简述}） | {✅ 安全 / ⚠ 谨慎 / ❌ 拒绝} |
| 决策人 | 已锁定 {N} 位（{Top3 职位}） | 🎯 |
| **💰 贸易体量** | **年进口 {trade_total_import_usd} / 年销售 {trade_total_revenue_usd} / 进口占销比 {trade_ratio_pct}% ({trade_year})** | {🔴 ≥20% / 🟡 10-20% / 🟢 <10%} |
| 进口结构 | {国家1} {占比1}% / {国家2} {占比2}% / {国家3} {占比3}% / Other | {🟢 高潜 / 🟡 中等 / 🔴 低潜} |
| **🚀 决策** | **{dim9_decision}** | |

📁 **完整档案**：[{文件名}](文件绝对路径)

🛡️ **自检状态**：sanity_check 17/17 PASS（Sheet ⑤ 已自动回写绿底 ✅）
💡 5 套切入话术 + 中英开发信全文已塞进 Sheet ① 决策摘要，**v2.5 起话术已自动引用贸易数据**，可直接复制发送。
```

---

## ❌ 反例（不允许出现）

- 只发"已生成完毕"不贴摘要表 → 学员看不到核心结论
- 不给文件绝对路径 → 学员找不到文件
- 不贴 sanity 状态 → 学员无法判断是否被 Auto 模型偷懒
- **缺『💰 贸易体量』行 / 『进口结构』行**（v2.5 必须）→ 第 10 维白做
- 表格用纯文字铺展（破坏 Markdown 渲染）

---

## 🛡️ Sanity FAIL 时的处理

如果 `sanity_check.py` exit code != 0，AI **绝对不能**继续贴摘要。必须：

1. 把 `[FAIL] Sxx ...` 错误信息原样贴出
2. 按提示修复 payload 字段（v2.5 高频 FAIL 场景）：
   - **S14 FAIL**：Sheet ① 顶部漏画贸易速览卡片 → 检查 excel_gen.py 是否走最新版
   - **S15 FAIL**：Sheet ② 缺第 10 维章节 → payload `dim10_trade` 字段缺失
   - **S16 FAIL**：分国家明细 < 3 国 → 重新查 Panjiva/ImportYeti 凑 3 个最大来源国
   - **S17 FAIL**：年度金额用了「暂未找到 / TBD」→ 必须真实查到 USD 数值，禁止占位
   - 其他常见：缺字段、话术 < 20 字、开发信 < 50 字、决策人 < 5
3. 重跑 `excel_gen.py` + `sanity_check.py`
4. 17/17 PASS 之后才输出此模板
