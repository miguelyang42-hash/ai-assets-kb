# 中文邮件模板结构

撰写中文邮件时参考此结构。

## 主题行模式

| 场景 | 模式 | 示例 |
|------|------|------|
| 付款方案 | 关于[产品/项目]的[核心议题] | 关于灌装机项目付款方案的优化建议 |
| 价格说明 | 关于[产品]报价的详细说明 | 关于口罩报价的价格构成说明 |
| 样品跟进 | [产品]样品——测试支持与后续步骤 | PVC瑜伽垫样品——测试支持与后续步骤 |
| 交期更新 | [产品]发货更新——调整后的交期安排 | LED显示屏发货更新——调整后的交期安排 |
| 投诉回复 | 关于[问题]的调查与解决方案 | 关于褪色问题的调查与解决方案 |
| 沉默跟进 | [产品]——最新进展与确认 | 灌装机——生产排期更新与确认 |
| 客户挽回 | 重新联系——[新能力/新产品]上线 | 重新联系——全自动包装线上线通知 |

## 开头（1段）

- 确认客户的立场或关切
- 表达理解但不让步
- 如有前期沟通，简要引用

开头模板（按场景）：
- **价格异议**："感谢您对我们报价的详细反馈。我们理解价格是您决策中的关键因素……"
- **付款条款**："感谢您的坦诚沟通。我们非常理解[产品]作为一项重大投资，确实涉及较大的资金安排……"
- **投诉处理**："感谢您及时反馈此问题。我们非常重视质量问题，希望尽快为您解决……"
- **跟进沉默**："希望一切顺利。我想就我们之前关于[话题]的讨论做一个跟进……"
- **客户挽回**："距离我们上次联系已有一段时间，我想分享一些可能对您业务有帮助的最新进展……"

## 正文（2-4段）

- 简要说明商业逻辑
- 提出反提案或替代方案
- 提供选择，而非最后通牒
- 多个选项时使用编号列表
- 包含具体数字、日期或百分比

正文结构：
1. **理由段**：简要解释原因（1-2句）
2. **方案段**：具体提案及选项（使用编号列表）
3. **支持段**：附加价值或保证（可选）

## 结尾（1段）

- 明确的下一步或问题
- 专业的结束语
- 让客户容易回复

结尾模板：
- "您看这个方案是否更符合您的财务预算？"
- "如果方便的话，我们可以安排一次电话详细讨论。"
- "能否在[日期]前确认，以便我们为您锁定生产排期？"
- "期待您对以上方案的反馈。"

## 语气原则

- 专业但不生硬（professional but not stiff）
- 坚定但不强硬（firm but not rigid）
- 给对方台阶（give face-saving options）
- 用事实代替情绪（use facts, not emotions）
- 段落简短，每段2-3句（keep paragraphs short）
- 非我方过错时避免"抱歉"
- 公司决策用"我们"，个人承诺用"我"

## 称呼规范

| 关系 | 称呼 |
|------|------|
| 新客户 | 亲爱的[客户名] / Dear [Customer Name] |
| 老客户 | [客户名]您好 / Hi [Customer Name] |
| 正式场合 | 尊敬的[客户名] |

## 签名规范

```
祝商祺，
[您的名字]
[职位]
[公司名]
```
