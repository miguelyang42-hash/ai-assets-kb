# Trade Email Case Copilot — 使用说明书

## 1. 概况

Trade Email Case Copilot 是一个面向外贸业务员的智能谈判辅助工具。当业务员在跟单过程中遇到客户的异议、刁难或沉默时，可以通过此工具获得基于真实案例库的回复建议、邮件草案和快捷短句。

**底层逻辑**：案例优先、检索驱动。工具会从结构化的案例卡片库（覆盖 300+ 真实谈判场景）中匹配最相关的案例，提取谈判思维，再生成可发送的回复内容。不是通用文案生成器，而是"案例检索 + 谈判策略 + 文案输出"三位一体的辅助系统。

**核心定位**：超级业务员助手。业务员遇到任何客户沟通问题，都可以在对话窗口中提问，工具会自动调取案例库、匹配策略、生成回复。

**适用人群**：
- 外贸业务员（新手和资深均适用）
- 外贸团队主管（用于培训和话术标准化）
- 跨境电商运营人员

## 2. 核心功能

| 功能 | 说明 | 输出语言 |
|------|------|----------|
| **问题诊断** | 自动识别客户异议的类别、谈判阶段、客户类型、核心风险与机会 | 中英双语 |
| **案例匹配** | 从案例库中匹配至少 3 个最相关案例，提供摘录和谈判思维 | 中英双语 |
| **应对策略** | 给出分步策略（共情→反提案）、禁忌话术、可让步筹码 | 中英双语 |
| **邮件草案** | 同时输出中文和英文完整邮件（含主题行），可直接发送 | 中文 + 英文 |
| **WhatsApp 快捷短句** | 中英双语各 4 条，按"共情→转折→方案→收尾"递进，可直接粘贴 | 中文 + 英文 |
| **后续行动建议** | 给出 2-4 条可操作的下一步建议 | 中英双语 |

### 2.1 智能分类与路由

工具会自动识别问题类别并路由到对应的案例卡片库：

| 问题类别 | 对应案例库 | 典型关键词 |
|----------|-----------|-----------|
| 样品问题 | 10-case-cards-samples.md | 样品、打样、sample、proof |
| 价格谈判 | 11-case-cards-price.md | 价格、报价、折扣、price、discount |
| 交付与付款 | 12-case-cards-delivery-payment.md | 付款、定金、运费、交期、分期 |
| 跟进与售后 | 13-case-cards-followup-after-sales.md | 不回复、投诉、退款、跟进 |

### 2.2 跨主题智能处理

当客户问题涉及多个类别时（如"价格太高且要求分期"），工具会：
1. 识别主要类别和次要类别
2. 从多个案例库中匹配案例
3. 综合生成跨主题的回复策略

### 2.3 渠道自适应

工具支持多种沟通渠道的自动适配：

| 渠道 | 触发词 | 输出格式 |
|------|--------|----------|
| 邮件（默认） | 无需指定 | 完整邮件格式 |
| WhatsApp | WhatsApp、快捷回复 | 短消息格式（6-8条） |
| 微信 | 微信、WeChat | 短消息格式 |
| 阿里旺旺 | TM、旺旺 | 超短消息格式 |
| LinkedIn | LinkedIn | 专业短消息格式 |
| 其他 | Skype、Telegram 等 | 短消息格式 |

### 2.4 语气调节

支持根据场景或用户指令调节语气：

| 语气 | 触发词 | 适用场景 |
|------|--------|----------|
| 专业（默认） | 无需指定 | 大多数场景 |
| 强硬 | "强硬一点"、"firmer" | 催款、价格底线 |
| 温和 | "温和一点"、"softer" | 投诉处理、信任修复 |
| 紧急 | "紧急"、"urgent" | 截止日期、限时优惠 |
| 轻松 | "轻松一点"、"casual" | 老客户日常沟通 |

### 2.5 用户自有案例支持

业务员可以上传自己的案例或客户邮件原文，工具会：
1. 使用相同的诊断框架分析用户案例
2. 仍然匹配内置案例库作为参考
3. 将用户的具体情境融入输出内容

## 4. 如何使用

### 4.1 基本用法

直接在对话窗口中描述你遇到的客户问题，例如：

> 客户说我们的灌装机价格太高，要求降价 20%，否则就找别的供应商。

工具会自动完成以下 6 个维度的输出（**固定结构，不可省略**）：

1. **问题诊断** — 识别问题类型、谈判类型、阶段、客户类型、风险、机会
2. **案例匹配** — 匹配 3+ 案例，附来源、摘录与谈判思维
3. **应对策略** — 共情确认 → 反提案（含多个方案）→ 禁忌话术 → 可让步筹码
4. **邮件草案** — 中文 + 英文完整邮件（含主题行）
5. **WhatsApp 快捷短句** — 中文 4 条 + 英文 4 条（共情→转折→方案→收尾）
6. **后续行动建议** — 2-4 条可操作建议

### 4.2 提供客户原话（推荐）

提供客户的原始英文消息可以大幅提升匹配精度：

> 客户原话是："We like your filling machine but the price is beyond our budget. Can you offer 20% discount or we'll have to look at other suppliers."
> 这是个老客户，之前下过两次单。帮我回复。

### 4.3 指定渠道

如果需要通过 WhatsApp / 即时聊天回复，在提问时说明：

> 客户在 WhatsApp 上说想分期付尾款，帮我回复。

工具会自动切换为短消息格式，快捷短句扩展为 6-8 条。

### 4.4 调节语气

> 帮我写一封强硬一点的催款邮件，客户已经拖了两个月了。

> 客户投诉质量问题，帮我温和一点回复。

### 4.5 仅分析模式

如果只需要诊断和策略，不需要邮件草案：

> 帮我分析一下这个客户的情况，先不用写邮件。

此时输出维度 1、2、3、6，跳过 4 和 5。

### 4.6 仅英文模式

> 只要英文回复就好。客户说 "Your price is too high compared to other suppliers."

### 4.7 上传自己的案例

> 我之前遇到过类似的情况，客户说了这些：[粘贴客户邮件原文]
> 我当时是这样回复的：[粘贴你的回复]
> 帮我看看有没有更好的方式。

### 4.8 多轮对话调整

首次输出后，可以继续调整：

> 再强硬一点。
> 换个角度试试。
> 加上一个关于交期的说明。
> 邮件太长了，帮我精简一下。

### 4.9 CLI 工具（高级用法）

脚本 `scripts/main.py` 提供六个命令：

```bash
# 诊断客户消息，返回分类、置信度评分、渠道、语气、模式
python scripts/main.py diagnose "The price is too high"

# 诊断中文消息
python scripts/main.py diagnose "客户要求分期付款"

# 根据分类获取对应的案例卡片文件路径
python scripts/main.py route price

# 验证输出是否包含全部 6 维度和至少 3 个案例
python scripts/main.py validate output.txt

# 检测沟通渠道
python scripts/main.py channel "客户在WhatsApp上问价格"

# 检测语气偏好
python scripts/main.py tone "帮我写一封强硬一点的邮件"

# 批量诊断（每行一个消息）
python scripts/main.py batch messages.txt
```

## 5. 输入说明

| 输入项 | 必需 | 说明 | 示例 |
|--------|------|------|------|
| 客户问题描述 | 必需 | 描述你遇到的客户沟通问题 | "客户嫌价格贵，要求降价" |
| 客户原话 | 强烈推荐 | 最好提供客户的原英文消息 | "Your price is 20% higher than..." |
| 产品/设备类型 | 推荐 | 如灌装机、包装机、口罩等 | "灌装机" |
| 客户类型 | 可选 | 新客户 / 老客户 / 贸易商 / 品牌方 / OEM | "老客户，下过两次单" |
| 当前阶段 | 可选 | 询价 / 报价 / 样品 / 谈判 / 生产 / 发货 / 售后 | "报价后跟进阶段" |
| 回复渠道 | 可选 | 邮件（默认）/ WhatsApp / 微信 / TM 等 | "WhatsApp" |
| 语气偏好 | 可选 | 专业 / 强硬 / 温和 / 紧急 / 轻松 | "强硬一点" |
| 订单金额 | 可选 | 大概金额范围 | "约 5 万美金" |

**信息越完整，输出越精准。** 最低要求是提供客户问题描述，其余信息工具会通过诊断问题（最多 3 个）来补充。

## 6. 输出说明

工具直接输出文本内容到对话窗口，固定包含以下 6 个维度：

### 维度 1：问题诊断
- 问题类别、谈判类型、当前阶段、客户类型
- 核心风险（处理不当的后果）
- 核心机会（可利用的杠杆）

### 维度 2：案例匹配
- 至少 3 个匹配案例
- 每个案例包含：来源引用、案例摘要（清洗后）、回复思维

### 维度 3：应对策略
- 第一步：共情确认（Acknowledge）
- 第二步：反提案（Counter-offer），含多个方案选项
- 切忌说：至少 2 条禁忌话术及原因
- 可让步筹码：按让步程度从小到大排列

### 维度 4：邮件草案
- 中文邮件：含主题行、正文、签名
- 英文邮件：含主题行、正文、签名
- 可直接复制发送

### 维度 5：WhatsApp 快捷短句
- 中文 4 条：共情 → 转折 → 方案 → 收尾
- 英文 4 条：共情 → 转折 → 方案 → 收尾
- 每条独立可用，可直接粘贴

### 维度 6：后续行动建议
- 2-4 条具体可操作的建议
- 针对当前场景定制，非通用建议

## 7. 应用场景

| 场景类别 | 典型问题 | 推荐输入 |
|----------|----------|----------|
| **样品阶段** | 样品发错、客户拒付样品费、样品后沉默、样品测试不通过 | 提供样品类型和客户反馈 |
| **价格谈判** | 客户嫌贵、对比竞品、目标价过低、涨价通知、网页价格不符 | 提供报价和客户目标价 |
| **付款条款** | 要求分期、要求 OA 账期、拒付定金、尾款拖延、L/C 谈判 | 提供订单金额和客户要求 |
| **交付问题** | 交期延迟、运费上涨、客户要求退款、清关延迟 | 提供延迟原因和时间 |
| **跟进沉默** | 报价后无回复、已读不回、老客户流失、新客户不回复 | 提供跟进次数和最后沟通内容 |
| **售后投诉** | 质量投诉、运输损坏、要求退货退款、差评威胁 | 提供投诉内容和证据情况 |
| **高价值设备** | 灌装机等大型设备分期付款、定制设备付款方案 | 提供设备类型和金额 |
| **客户挽回** | 老客户停止下单、买手更换、竞争对手抢单后回归 | 提供客户历史和流失原因 |

## 8. 注意事项

1. **至少匹配 3 个案例** — 硬性要求，保证回复有据可依
2. **6 维度输出不可省略** — 除非用户明确要求"仅分析"模式
3. **不捏造案例** — 所有引用必须来自实际案例库文件
4. **信息脱敏** — 不恢复公司名称、人名、电话、网址等敏感信息
5. **不直接粘贴原始 OCR 文本** — 案例摘录需经过清洗和重写
6. **保护利润** — 默认不建议大幅让步，除非用户明确要求
7. **输出结构稳定** — 每次回复的维度名称、顺序、子字段完全一致
8. **不建议发货后付款** — 对高价值或定制商品，绝不建议接受发货后付款（除非有 L/C 保障）
9. **案例引用格式统一** — 始终使用 `参考文件 / 来源块 / 案例主题` 格式
10. **多轮对话支持** — 首次输出后可继续调整语气、角度、内容

## 9. 常见问题（FAQ）

**Q: 工具能处理哪些语言的客户消息？**
A: 支持中文和英文输入。客户原话建议提供英文原文以提高匹配精度。

**Q: 如果我的问题跨越多个类别怎么办？**
A: 工具会自动识别主要类别和次要类别，从多个案例库中匹配案例，综合生成回复。

**Q: 输出的邮件可以直接发送吗？**
A: 可以。邮件草案设计为可直接发送的格式，但建议根据你的具体情况做微调（如替换占位符 `[客户名]`、`[产品名]` 等）。

**Q: 如果案例库中没有完全匹配的案例怎么办？**
A: 工具会声明"无精确匹配案例"，然后使用最接近的案例推理，仍然提供 3+ 案例参考。

**Q: 可以只要英文回复吗？**
A: 可以。输入时说"只要英文"或"English only"即可。

**Q: 如何让回复更强硬/更温和？**
A: 在输入中加上语气指令，如"强硬一点"、"温和一点"、"紧急"等。也可以在首次输出后说"再强硬一点"进行调整。

## 10. 在 Accio Work 中使用

如果你使用 Accio Work 平台，可以通过以下方式集成此技能：

### 10.1 安装与配置

1. 将 `trade-email-case-copilot` 目录放置在你的技能库中
2. 确保 Accio Work 的配置已加载本技能的 `SKILL.md` 和 `config.yaml`
3. 验证 `references/` 目录下的所有案例文件已正确加载

### 10.2 调用方式

在 Accio Work 中调用 `/trade-email-case-copilot` 命令，然后在对话窗口中输入客户问题。

### 10.3 使用示例

```
/trade-email-case-copilot
客户说灌装机价格太高，要求降价20%，否则找别的供应商。这是老客户，之前下过3次单。
```

### 10.4 批量处理

支持批量处理多个客户问题，每次独立输出 6 维度回复：

```
/trade-email-case-copilot
问题1: 客户要求分期付款
问题2: 另一个客户报价后不回复
```

### 10.5 注意事项

- 确保网络连接稳定，案例库文件较大（约 460KB）
- 首次加载可能需要几秒钟
- 建议在使用前先测试一个简单问题确认技能正常工作
