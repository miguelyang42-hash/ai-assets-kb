# alibaba-hero-image-gen v1.0.0

> 阿里巴巴国际站产品主图生成 Skill — 全行业通用，每次必问 5 题 + 必爬竞品风格，交付符合 B2B 买家审美的专业主图。

---

## 30 秒起步

### 第一步：触发 Skill

在 Agent 对话框中说以下任意一句话即可触发：

- "帮我做阿里国际站主图"
- "产品主图生成"
- "B2B主图作图"
- "alibaba hero image"

### 第二步：使用客户喊话模板（强烈建议）

在触发时同时粘贴以下内容，防止 AI 跳过流程：

```
请严格按照 alibaba-hero-image-gen v1.0 SKILL.md 执行：
第一步必须完成 5 问收集（不可跳过），
第二步必须爬取 Alibaba.com Top Ranking 对应类目竞品主图风格，
第三步再按用户选择的类型逐张生成主图。
禁止跳过任何步骤直接作图。
```

### 第三步：回答 5 题

AI 会依次向你提问：

| 题号 | 内容 |
|---|---|
| Q1 | 上传产品白底图 |
| Q2 | 产品名称 / 三级类目 |
| Q3 | 选择主图类型（1-6 种） |
| Q4 | 目标市场 & 风格偏好 |
| Q5 | 生成数量（1-6 张） |

### 第四步：等待生成

AI 自动完成：爬取竞品风格 → 逐张生成主图 → 展示结果

## 支持的 6 种主图类型

| # | 类型 | 说明 |
|---|---|---|
| ① | 产品主展示图 | 极简科技风，突出核心参数，对标 Dyson 视觉 |
| ② | 多颜色可选 | 多色矩阵并排，吸引 SKU 定制买家 |
| ③ | 多尺寸可选 | 多规格对比，适合有尺寸需求的买家 |
| ④ | 定制 LOGO | OEM/ODM 激光雕刻/丝印效果展示 |
| ⑤ | 定制包装盒 | 礼品盒/彩盒/OEM 包装展示 |
| ⑥ | 使用场景 | 模特/生活方式/真实使用环境 |
