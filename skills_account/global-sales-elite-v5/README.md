## 二、一键安装（推荐）

### Windows
1. 解压本压缩包到任意目录（建议 `D:/global-sales-elite-v5/`，路径中不要有空格更稳）。
2. 双击 `install.bat`。
3. 看到 `自检结果: 全绿 12/12 (ALL PASS)` 即安装成功。

### macOS / Linux
```bash
cd /path/to/global-sales-elite-v5
chmod +x install.sh
./install.sh
```

## 五、产物规范（V5.4 品牌版）

### Word 报告（每客户 1 份）
- **封面**：深海蓝（`#1F4E79`）品牌封面，含「小蜂学掌」「www.xfxz123.com」「客户名」「渠道 + 日期」
- **页眉**：左「🐝 小蜂学掌 | www.xfxz123.com」+ 右「精细化开发报告 | V5.4」+ 深蓝分隔线
- **页脚**：「© 小蜂学掌 www.xfxz123.com 版权所有，未经授权禁止转载」+ 页码
- **文件名**：`小蜂学掌_{英文简称} _ {画像} _ {国家} _ {等级}.docx`
- 8 大模块：评估 / 公司情报 / 5 维分析 / 联系人图谱 / 谈判策略 / 中英开发信 / 产品分析 / 落地建议

### Excel 群发总表（24 列）
- **行1**：品牌表头（深海蓝 `#1F4E79`，含「小蜂学掌 | www.xfxz123.com」）
- **行2**：金色分隔条（`#F2C94C`）
- **行3**：数据表头（绿色 `#00B050` + 白字加粗，冻结至此行下方）
- **末行**：版权表尾（浅灰 `#F2F2F2`，含版权声明）
- **文件名**：`小蜂学掌_{国家}{客群}{YYYYMMDD}.xlsx`

## 六、文件结构

