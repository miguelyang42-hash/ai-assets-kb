## 2. 输出标准（红线，不可降级）

### 2.1 文件夹与文件命名规则（强制：品牌前缀 + 国家+客群+日期）
| 类型 | 命名格式 | 示例 |
|:--|:--|:--|
| 📂 项目文件夹 | `[国家]_[客群]_[日期 YYYYMMDD]` | `美国_全屋定制_20260509` |
| 📊 群发 Excel | `小蜂学掌_{国家}{客群}{日期}.xlsx` | `小蜂学掌_美国全屋定制20260509.xlsx` |
| 📄 Word 报告 | `小蜂学掌_{英文简称} _ {画像} _ {国家} _ {等级}.docx` | `小蜂学掌_DuraSupreme _ 美国定制橱柜巨头 _ USA _ A+.docx` |

**细则**：
- 国家用中文（美国 / 欧洲 / 日本 / 中东 / 巴西…），不允许英文简写。
- 客群用中文短语（全屋定制 / 橱柜门板厂 / 灯具品牌商 / 五金分销商…）。
- 日期固定 8 位 YYYYMMDD，按本机当日。
- 同日同国家+客群的多次执行，使用同一文件夹，Excel 自动追加。
- **所有输出文件必须含「小蜂学掌_」前缀**（R12）。

## 3. 自动化工作流

### Step A: 构建标准 JSON Payload
JSON Schema 强制校验（`payload.schema.json`，Draft-07）。**关键字段**：
- `channel`：枚举 `google` / `instagram` / `facebook` / `linkedin` / `tiktok` / `manual`
- `country` / `segment`：用于命名与归档
- `v4_contacts`：minItems = 3

### Step B: 一键执行
```bash
# 跨平台（Win/Mac/Linux 通用）
python main.py payload.json
# 或自定义输出根目录
python main.py payload.json --out-dir "D:/Personal/Desktop/主动开发"
```

`main.py` 内部自动：
1. 输出品牌启动通知框（铁律 #0）
2. 校验 payload（jsonschema Draft7Validator）
3. 按平台选择默认根目录
4. 创建 `[国家]_[客群]_[日期]/` 项目文件夹
5. 调用 `word_gen.py` 生成带品牌封面/页眉/页脚的 Word 报告
6. 调用 `excel_sync.py` 追加含品牌表头表尾的群发表
7. 写入 `logs/<run_id>.log` 完整日志
8. 输出文件绝对路径通知框

### Step C: 退出码语义
| 退出码 | 含义 |
|:--:|:--|
| 0 | 成功 |
| 1 | VALIDATION_FAILED（schema 校验失败） |
| 2 | PLATFORM_FAILED（平台/路径异常） |
| 3 | IO_FAILED（磁盘/编码异常） |

1. 目录命名 `国家_客群_日期` 三段不可缺。
2. Word 标题/文件名 4 段（英文简称/画像/国家/等级）+ 品牌前缀不可缺。
3. Excel 24 列必须全部填充；邮箱缺失 → `(预测格式)`。
4. 决策人 ≥3 位；5 字段齐全。
5. 5 维深度分析 5 项必填，禁"不详"。
6. 开发信首句必须 Hook；中英文双语全文。
7. 严禁 Word 内出现 Markdown 符号。
8. Excel 行1 必须为小蜂学掌品牌表头行（深海蓝底，含 www.xfxz123.com）。
9. Excel 末行必须为版权表尾行（浅灰底，含版权声明）。
10. Word 必须含封面（深海蓝标题块）、页眉（品牌 + 分隔线）、页脚（版权 + 页码）。
11. 所有输出文件名必须含「小蜂学掌_」前缀。
12. 生成完成后必须输出含绝对路径的通知框（main.py 自动处理）。
