# XPES 开发信策略进化记录 (2026-06-16)

## 开发信 2.0 准则 (由阿D定义)
1. 分析网站与主要产品。
2. 挖掘独特观察点与业务挑战。
3. 严禁第一句介绍公司、严禁客套话。
4. 篇幅 < 150 字，业务价值导向。
5. 以简单问题结尾，不直接推销。
6. 目标：优先级为 1.回复 -> 2.会面 -> 3.样品 -> 4.RFQ。

## 运营执行规范 (2026-06-16 新增)
1. **定时发送**：根据客户所在国家的上班时间（通常为当地 9:00 AM）定时发送邮件。
2. **可见性**：所有邮件必须通过 Gmail 接口发送，确保在“已发送”文件夹可见。
3. **回复管理**：
    - 严禁主动回复客户邮件。
    - 每日定时浏览收件箱，整理客户回复内容。
    - 统计并分析已读率与回复率，作为自进化的数据基础。

## 成功应用案例
- **Woodstream (Dynatrap)**: 切入点为“离网户外生活”与“传统插电产品的局限性”。
- **Domyown.com**: 切入点为“化学药剂安全忧虑”与“非化学专业级替代品”。
